# ÉCLAT 3D assets

The four fragrance bottles are original, custom-authored GLB meshes generated by `generate_bottles.py`. Each model includes a hollow glass shell, a fragrance core, a neck, a separate multi-part cap, metallic trim, and a complete atomizer: a metal collar and stem, a fragrance-specific actuator, a dark front-facing aperture, and a translucent dip tube inside the bottle. The 3D viewer groups the cap shell and trim on a lift-off pivot so only the cap animates when opened. Three.js supplies the brand-specific physical glass and label materials at runtime.

The spray effect is emitted from the aperture's frontmost geometry point in model-local coordinates. The viewer transforms that point and its forward axis into world space before animating particles and mist in the 3D scene; the spray control opens the cap and waits for the lift animation to finish before requesting a burst.

The bottle profiles are fragrance-specific: Amber Noir is broad and architectural, Velvet Bloom has a softly rounded body and sculpted cap, Citrus Ombre is slim with a tapered cap, and Midnight Oud uses a squared silhouette with a faceted cap. Glass roughness and absorption are tuned separately for each scent; the 3D bottle viewer supports pointer, touch, and arrow-key rotation.

The four matching ingredient scenes (`*-ingredients.glb`) are original GLB assets generated by `generate_ingredients.py`. Each has its own grouped meshes and material textures: Amber Noir (amber, cedar, sandalwood, vanilla, cinnamon, pink pepper, saffron), Velvet Bloom (rose, jasmine, peony, musk), Citrus Ombre (bergamot, lemon, neroli, vetiver), and Midnight Oud (oud, leather, saffron, patchouli, sandalwood). The ingredient viewer loads the selected fragrance's GLB when it approaches the viewport, supports pointer rotation, and releases its renderer and active model when it leaves view. A bottle image remains visible if WebGL or a model is unavailable.

`studio_small_03_1k.hdr` is Poly Haven's *Studio Small 03* HDRI, released under CC0: https://polyhaven.com/a/studio_small_03 and https://polyhaven.com/license.

AI model-generation services were researched; for example, Meshy's text-to-3D workflow can export GLB but its generation API requires an authenticated API key. No credentials or generated models were available in this project, so the included, reproducible bottle meshes were authored locally instead.
